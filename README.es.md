# Pokédex

Proyecto de práctica para consumir una API pública con HTML, CSS y JavaScript puro (sin frameworks).
Carga los 151 Pokémon de la primera generación desde [PokeAPI](https://pokeapi.co/) y los muestra como
tarjetas con número, imagen oficial, tipos, altura y peso, con botones para filtrar por tipo.

Los 151 Pokémon se piden una sola vez en paralelo, se guardan en orden de número y se filtran en
memoria.

## Cómo correrlo

Abrir `index.html` en el navegador (o servir la carpeta con cualquier servidor estático, por ejemplo
Live Preview de VS Code). No requiere build ni dependencias.
